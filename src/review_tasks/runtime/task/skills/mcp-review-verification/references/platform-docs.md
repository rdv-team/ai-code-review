# Capability: platform-docs

**Когда использовать:** когда вопрос `verification` зависит от официальной документации платформы «1С:Предприятие»: существования и контракта объектов, методов, свойств, событий, параметров, сигнатур или поведения API платформы.
**Registry server id:** `onec-docs-mcp-remote`

## Правила проверки

- Выбирай MCP-инструмент и его параметры по актуальному описанию и схеме инструмента.
- Формулируй один конкретный вопрос о существовании, контракте, сигнатуре или поведении API платформы.
- Если вопрос касается конкретного API, используй его точное имя из видимого кода.
- Используй эту `reference` для проверки семантики конструкции по официальной документации платформы. Если нужно определить, является ли конкретный изменённый BSL-фрагмент синтаксически корректным или вызывает диагностику анализатора, используй `references/bsl-syntax-check.md`.
- Не считай отсутствие результата одного поиска доказательством отсутствия объекта, метода, свойства или другого API платформы. Если отсутствие API влияет на `keep/drop`, уточни запрос по точному имени и назначению проверяемой конструкции.
- Сопоставляй найденную документацию с видимым изменённым кодом. Сам факт существования API или штатного платформенного механизма не доказывает корректность его применения.
