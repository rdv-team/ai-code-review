# Capability: bsl-syntax-check

**Когда использовать:** когда вопрос `verification` зависит от синтаксической корректности изменённого BSL-фрагмента или от фактической диагностики BSL Language Server.
**Registry server id:** `onec-syntax-checker-mcp-remote`

## Правила проверки

- Выбирай MCP-инструмент и его параметры по актуальному описанию и схеме инструмента.
- Передавай минимальный самодостаточный BSL-фрагмент, достаточный для текущего вопроса `verification`.
- Не передавай весь модуль или большой несвязанный фрагмент, если для проверки достаточно меньшего участка.
- Используй эту `reference`, если нужно определить, является ли конкретный изменённый BSL-фрагмент синтаксически корректным или вызывает диагностику анализатора.
- Если вопрос касается смысла, контракта или допустимого поведения конструкции по официальной документации платформы, выбери `references/platform-docs.md`.
- Не интерпретируй отсутствие диагностики как доказательство логической корректности кода. Эта capability подтверждает только то, что относится к синтаксису и фактически возвращённым диагностикам.
