# Capability: ssl-library-search

**Когда использовать:** когда вопрос `verification` зависит от существования или поведения функциональности БСП: нужно проверить метод/общий модуль БСП, найти штатный механизм или выяснить, не дублирует ли изменённый код уже существующую функциональность БСП.
**Registry server id:** `onec-ssl-mcp-remote`

## Правила проверки

Формулируй `query` как один конкретный вопрос. Если Stage 1 передал `standard_hints.bsp_files`, трактуй каждый элемент как имя общего модуля БСП, не как путь к файлу. Включи это имя в `query` вместе с проверяемым методом/проблемой или описанием требуемого действия.

Примеры `query`:

- `ОбщегоНазначения.ЗначенияРеквизитовОбъекта: проверить назначение метода и корректность использования для чтения нескольких реквизитов`;
- `РаботаСФайлами: найти штатную функциональность БСП для временного хранения и последующего получения файла`.

Если visible BSL содержит незнакомое имя общего модуля БСП, сначала используй встроенную ниже карту только для распознавания имени и family. Проверяй поведение механизма, корректность его применения, наличие штатной реализации и возможное дублирование через MCP.

## Описание именования модулей в текущем списке

Строка — корневое имя; в `[]` — варианты с суффиксами контекста 1С.

Например:

- СтандартныеПодсистемы[ПовтИсп|Клиент|Сервер]

В коде могут быть варианты общих модулей:

- СтандартныеПодсистемы
- СтандартныеПодсистемыПовтИсп
- СтандартныеПодсистемыКлиент
- СтандартныеПодсистемыСервер

## Примеры вызовов общих модулей БСП в коде 1С

```bsl
ОбщегоНазначения.ЗначенияРеквизитовОбъекта(Объект, "ЭтоГруппа, ВидНоменклатуры");
СтроковыеФункцииКлиентСервер.ПодставитьПараметрыВСтроку(НСтр("ru = 'День рождения сотрудника: %1'"), Строка(Предмет));
ПараметрыОжидания = ДлительныеОперацииКлиент.ПараметрыОжидания(Форма);
```
