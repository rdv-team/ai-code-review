# Производительность коллекций

### std452: Поиск в коллекциях значений
- **Ключи:** `Найти`, `НайтиСтроки`, `СравнениеЗначений`, `Индексы.Добавить`, `Сортировать`
- **Критичность:** Важно
- **Инструкция:** Для быстрого поиска в больших таблицах значений должны быть созданы индексы. Предложить добавить индексы, если используется `НайтиСтроки` на большой таблице без индексации.
