# Работа с формами: элементы и обработчики

### std523: Обращение к свойству "ТекущаяСтрока" табличного поля
- **Ключи:** `ТекущаяСтрока`, `ТекущиеДанные`
- **Критичность:** Важно
- **Инструкция:** Агент должен проверить, что перед использованием `ТекущаяСтрока` проверено, что она не `Неопределено`.

### std545: Обращение из кода к пользовательским элементам управления формы
- **Ключи:** `ТекущаяСтраница`, `ТекущиеДанные`
- **Критичность:** Важно
- **Инструкция:** Агент должен убедиться, что обращение к элементам формы происходит с учетом их существования, например после проверки `Элементы.Найти()`.

### std463: Обработчик события ОбработкаПроверкиЗаполнения
- **Ключи:** `ОбработкаПроверкиЗаполнения`, `ПроверяемыеРеквизиты`
- **Критичность:** Критично
- **Инструкция:** Убедиться, что проверка выполняется для всех обязательных реквизитов и что сообщение об ошибке понятно.

### std686: Работа с параметром "Отказ" в обработчиках событий
- **Ключи:** `Отказ`, `Отказ = Истина`, `Отказ = Ложь`
- **Критичность:** Критично
- **Инструкция:** Если обработчик может прервать операцию, например `ПередЗаписью`, он должен корректно устанавливать `Отказ = Истина` при ошибке, иначе данные могут быть записаны некорректно.
