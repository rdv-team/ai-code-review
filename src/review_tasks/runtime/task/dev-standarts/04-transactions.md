# Транзакции

### std783: Транзакции: правила использования

- **Ключи:** `НачатьТранзакцию`, `ЗафиксироватьТранзакцию`, `ОтменитьТранзакцию`, `ТранзакцияАктивна`, `УстановитьИспользованиеИтогов`
- **Критичность:** Критично
- **Инструкция:** Читать стандарт, если в коде есть:
  - `НачатьТранзакцию` внутри метода, который может вызываться из `ПередЗаписью`, `ПриЗаписи`, `ОбработкаПроведения`, `ПередУдалением`.
  - `НачатьТранзакцию` ради простой записи объекта или набора записей без ответственного чтения.
  - Разнесение начала и завершения транзакции по разным методам.
  - Обработка `Исключение` внутри транзакции без явного `ОтменитьТранзакцию`.
  - Перехват ошибки внутри транзакции без `ВызватьИсключение`.
  - Обращения к БД после ошибки, пока транзакция еще активна.
  - Долгие действия внутри транзакции: внешние вызовы, большие циклы, тяжелые расчеты, массовая обработка.
  - Вложенные транзакции `НачатьТранзакцию` внутри вышестоящей `НачатьТранзакцию`.
  - Вложенная транзакция не пробрасывает `ВызватьИсключение` в вышестоящую; как следствие, риск ошибки `В данной транзакции уже происходили ошибки`.
- **Важные уточнения:**
  - В 1С вложенных транзакций нет. Повторный `НачатьТранзакцию` внутри активной транзакции не создает новую транзакцию — только повышение счетчика, ошибки не будет. Реальная фиксация/отмена — на верхнем уровне. Если внутри вложенного уровня была отмена или ошибка, вся верхняя транзакция помечается как битая. Итог: при завершении верхнего уровня все изменения откатятся.
  - При вложенных транзакциях в конце `Исключение` добавлять `ВызватьИсключение`. Иначе ошибка не уйдет выше, внешняя транзакция не отменится явно, и платформа даст ошибку: `В данной транзакции происходила ошибка`.
  - Не считать сам факт `НачатьТранзакцию` внутри уже активной транзакции автоматической ошибкой.
  - Ошибок на СУБД не будет.
  - `ТранзакцияАктивна()` не обязательна. Это возможная защитная проверка/документирование контракта метода.
  - Если метод может вызываться и самостоятельно, и из внешней транзакции, собственный паттерн `НачатьТранзакцию` / `ЗафиксироватьТранзакцию` в `Попытка` / `Исключение` допустим.
