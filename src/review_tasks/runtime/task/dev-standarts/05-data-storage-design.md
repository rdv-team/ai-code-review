# Проектирование хранения данных

### std683: Общие сведения об организации хранения данных
- **Ключи:** `Константы`, `Справочники`, `Документы`, `РегистрыСведений`, `РегистрыНакопления`
- **Критичность:** Важно
- **Инструкция:** Агент проверяет, что выбран правильный тип объекта для хранения. Например, константы не должны использоваться для часто меняющихся данных.
