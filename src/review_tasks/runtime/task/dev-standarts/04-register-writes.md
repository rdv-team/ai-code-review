# Запись в регистры

### rdv1: Чтение и запись набора записешй регистра сведений (риск deadlock)
- **Ключи:** `НаборЗаписей.Прочитать() ... НаборЗаписей.Записать()`
- **Критичность:** Критично
- **Инструкция:** Если в явной или неявной транзакции есть конструкция `НаборЗаписей.Прочитать()` и далее `НаборЗаписей.Записать()`, это может привести к deadlock из-за повышения уровня блокировок при параллельном выполнении. Правильно вместо `НаборЗаписей.Прочитать()` использовать чтение через `Новый Запрос` или заранее устанавливать управляемую исключительную блокировку.

### std792: Многократная запись регистров сведений и накопления
- **Ключи:** `СоздатьНаборЗаписей`
- **Критичность:** Критично
- **Инструкция:** Агент должен обнаружить, если в цикле происходит `НаборЗаписей.Записать()` - это антипаттерн. Набор записей должен формироваться и записываться один раз.

### std447: Использование объекта РегистрСведенийМенеджерЗаписи
- **Ключи:** `МенеджерЗаписи`, `СоздатьМенеджерЗаписи`, `СоздатьНаборЗаписей`
- **Критичность:** Важно
- **Инструкция:** Для записи одной записи регистра сведений используй `МенеджерЗаписи`, для пакетной - `НаборЗаписей` и подходящий `РежимЗамещения` для платформы 8.3.25 и выше.
