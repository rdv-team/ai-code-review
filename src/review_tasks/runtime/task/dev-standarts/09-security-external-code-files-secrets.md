# Безопасность: внешний код, файлы, пароли

### std770: Ограничения на использование Выполнить и Вычислить на сервере
- **Ключи:** `Вычислить`, `Выполнить Алгоритм`
- **Критичность:** Критично
- **Инструкция:** Использование `Выполнить Алгоритм` и `Вычислить` небезопасно. Отметить как потенциальную уязвимость и предложить альтернативы.

### std542: Доступ к файловой системе из кода конфигурации
- **Ключи:** `ЗапуститьПриложение`, `ПолучитьИмяВременногоФайла`, `КаталогВременныхФайлов`, `ЧтениеТекста`, `ЗаписьТекста`
- **Критичность:** Критично
- **Инструкция:** Проверить, что пути файлов не формируются из пользовательского ввода, и что временные файлы удаляются после использования.

### std669: Ограничение на выполнение внешнего кода
- **Ключи:** `HTTPСоединение`, `FTPСоединение`, `ПодключитьВнешнююКомпоненту`, `УстановитьВнешнююКомпоненту`, `ЗагрузитьВнешнююКомпоненту`
- **Критичность:** Критично
- **Инструкция:** Проверить наличие таймаутов, проверку ответа, обработку ошибок соединения.

### std740: Безопасное хранение паролей
- **Ключи:** `ПрочитатьДанныеИзБезопасногоХранилища`, `ЗаписатьДанныеВБезопасноеХранилище`, `Пароль`, `Токен`, `БезопасноеХранилище`
- **Критичность:** Критично
- **Инструкция:** Агент проверяет, что пароли и токены не хранятся в тексте, а используются методы безопасного хранилища.
