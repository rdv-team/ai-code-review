# Клиент-серверное взаимодействие и модули форм

### std630: Правила создания модулей форм
- **Ключи:** `ПриСозданииНаСервере`, `&НаКлиенте`, `&НаСервере`
- **Критичность:** Критично
- **Инструкция:** Убедиться, что тяжелые операции (запросы, расчеты) не выполняются на клиенте, а серверные вызовы не делаются в цикле с клиента.

### std487: Минимизация количества серверных вызовов и трафика
- **Ключи:** `&НаКлиенте`, `&НаСервере`, `&НаСервереБезКонтекста`
- **Критичность:** Критично
- **Инструкция:** Проверить, что серверные вызовы не делаются в цикле с клиента.
```bsl
// Плохо: несколько серверных вызовов
&НаКлиенте
Процедура Обработать(Команда)
    Данные1 = ПолучитьДанные1НаСервере();
    Данные2 = ПолучитьДанные2НаСервере();
    Данные3 = ПолучитьДанные3НаСервере();
КонецПроцедуры

// Хорошо: один серверный вызов
&НаКлиенте
Процедура Обработать(Команда)
    ВсеДанные = ПолучитьВсеДанныеНаСервере();
КонецПроцедуры

&НаСервереБезКонтекста
Функция ПолучитьВсеДанныеНаСервере()
    Результат = Новый Структура;
    Результат.Вставить("Данные1", ПолучитьДанные1());
    Результат.Вставить("Данные2", ПолучитьДанные2());
    Результат.Вставить("Данные3", ПолучитьДанные3());
    Возврат Результат;
КонецФункции
```

### std636: Контекстная и внеконтекстная передача управления на сервер
- **Ключи:** `&НаСервере`, `&НаСервереБезКонтекста`
- **Критичность:** Важно
- **Инструкция:** Определить, можно ли заменить `&НаСервере` на `&НаСервереБезКонтекста` для снижения трафика.
```bsl
// Плохо: передает полный контекст формы
&НаСервере
Функция ПолучитьДанныеНаСервере()
    Возврат ВыполнитьЗапрос();
КонецФункции

// Хорошо: без передачи контекста
&НаСервереБезКонтекста
Функция ПолучитьДанныеНаСервере(Параметры)
    Возврат ВыполнитьЗапрос(Параметры);
КонецФункции
```

### std642: Длительные операции на сервере
- **Ключи:** `ДлительныеОперации`, `ПриКомпоновкеРезультата`, `ДлительныеОперацииКлиент`
- **Критичность:** Критично
- **Инструкция:** Если на сервере выполняется долгий запрос или расчет, предложить обернуть его в `ДлительныеОперации`.
