# Запросы: соединения и динамические списки

### std655: Ограничения на соединения с вложенными запросами и виртуальными таблицами
- **Ключи:** `ЛЕВОЕ СОЕДИНЕНИЕ (ВложенныйЗапрос)`, `ВНУТРЕННЕЕ СОЕДИНЕНИЕ (ВложенныйЗапрос)`
- **Критичность:** Важно
- **Инструкция:** Агент должен обнаружить соединения, где в качестве источника используется вложенный запрос, и предупредить о потенциальных проблемах с производительностью. По возможности предложить переписать с использованием временных таблиц.

### std656: Ограничения на использование вложенных запросов в условии соединения
- **Ключи:** `ВложенныйЗапрос`, `И Таблица.Поле В (ВложенныйЗапрос)`
- **Критичность:** Важно
- **Инструкция:** Агент должен найти случаи, когда условие соединения содержит подзапрос, и предложить переписать с использованием временных таблиц.

### std732: Запросы в динамических списках
- **Ключи:** `Форма.Список.ТекстЗапроса`, `Форма.Списка`, `ДинамическийСписок`
- **Критичность:** Важно
- **Инструкция:** Неправильно пытаться реализовать в запросе динамического списка тяжелые запросы, виртуальные таблицы остатков, соединения с подзапросами или временные таблицы. Правильно оставить легкий запрос в 1-4 источника. Для вывода остатков применять отборы или обработчик формы `ПриПолученииДанныхНаСервере`.
