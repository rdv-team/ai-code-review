# Блокировки и ответственное чтение данных

### std648: Ответственное чтение данных
- **Ключи:** `Запрос.Выполнить`, `ПолучитьОбъект`, `БлокировкаДанных`, `НачатьТранзакцию`, `Записать`
- **Критичность:** Критично
- **Инструкция:** Если результат чтения используется для последующей записи данных, формирования движений, передачи целостного набора данных во внешнюю систему или принятия бизнес-решения, влияющего на изменения, должен проверить, что:
  - Чтение выполняется внутри транзакции или внутри системной транзакции платформы.
  - Управляемая блокировка установлена до чтения данных.
  - Для данных, которые будут изменяться, используется исключительная блокировка.
  - Для данных, которые только читаются ответственно, используется разделяемая блокировка.
  - Чтение и последующая запись не разорваны фиксацией транзакции.
  - При ошибке транзакция отменяется.
  - Для изменяемых ссылочных объектов дополнительно используется объектная блокировка.

### std490: Блокировка данных объекта для редактирования из кода

- **Ключи:** `ПолучитьОбъект`, `Объект.Записать`, `Объект.Заблокировать`, `ЗаблокироватьДанныеДляРедактирования`
- **Критичность:** Критично
- **Инструкция:** Если код изменяет существующий объект ИБ из встроенного языка, должен проверить:
  - До изменения объекта установлена объектная блокировка.
  - Использован `Объект.Заблокировать()` или `ЗаблокироватьДанныеДляРедактирования(Ссылка)`.
  - Блокировка стоит до изменения реквизитов, табличных частей и вызова `Объект.Записать()`.
  - `БлокировкаДанных` из std648 не заменяет объектную блокировку std490, если изменяется существующий ссылочный объект.
