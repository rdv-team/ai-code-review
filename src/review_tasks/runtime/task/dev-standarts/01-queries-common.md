# Запросы: общие правила и выборка данных

### std434: Использование ключевых слов "ОБЪЕДИНИТЬ" и "ОБЪЕДИНИТЬ ВСЕ" в запросах
- **Ключи:** `ОБЪЕДИНИТЬ`, `ОБЪЕДИНИТЬ ВСЕ`
- **Критичность:** Важно
- **Инструкция:** `ОБЪЕДИНИТЬ ВСЕ` быстрее, но не удаляет дубликаты. Если дубликаты недопустимы, должен использоваться `ОБЪЕДИНИТЬ`. Агент должен проверить, нет ли риска появления дублей при `ОБЪЕДИНИТЬ ВСЕ`.

### std436: Многократное выполнение однотипных запросов
- **Ключи:** `Запрос.Выполнить`, `Цикл`
- **Критичность:** Критично
- **Инструкция:** Если `Запрос.Выполнить()` находится внутри цикла (`Для`, `Пока`, `Для каждого`), это классический антипаттерн производительности. Агент должен отметить это как дефект. Исключение: запрос изменяет свои параметры внутри цикла и выполняется однократно - проверь, что параметры установлены до вызова.
```bsl
// Плохо: N обращений к базе
Для Каждого Строка Из Данные Цикл
    Запрос = Новый Запрос("ВЫБРАТЬ ... ГДЕ Ссылка = &Ссылка");
    Запрос.УстановитьПараметр("Ссылка", Строка.Ссылка);
    РезультатЗапроса = Запрос.Выполнить();
КонецЦикла;

// Хорошо: 1 обращение к базе
Запрос = Новый Запрос;
Запрос.Текст =
"ВЫБРАТЬ ...
|ГДЕ
|   Ссылка В (&СписокСсылок)";
Запрос.УстановитьПараметр("СписокСсылок", Данные.ВыгрузитьКолонку("Ссылка"));
РезультатЗапроса = Запрос.Выполнить();
```

### std438: Проверка на пустой результат выполнения запроса
- **Ключи:** `РезультатЗапроса.Пустой`, `Пустой`, `Выборка.Следующий`
- **Критичность:** Важно
- **Инструкция:** После `Запрос.Выполнить()` или `Выбрать()` обязательно должна быть проверка `Если РезультатЗапроса.Пустой() Тогда ...` перед вызовом `Выборка.Следующий()`. Агент должен обнаружить пропуск такой проверки и пометить как дефект.

### std496: Чтение отдельных реквизитов объекта из базы данных
- **Ключи:** `ЗначенияРеквизитовОбъекта`, `Запрос.Выполнить`, `ПолучитьОбъект`
- **Критичность:** Важно
- **Инструкция:** Если для чтения одиночного реквизита используется `ПолучитьОбъект()` или обращение к реквизитам через точку из ссылки (например, `Контрагент = ДокументСсылка.Контрагент`), агент должен предложить заменить на запрос или использование БСП `ОбщегоНазначения.ЗначениеРеквизитаОбъекта(ДокументСсылка, "Контрагент")` или другие подходящие методы этого класса для повышения производительности.

### std725: Оптимизация использования оперативной памяти
- **Ключи:** `Выгрузить`, `Выбрать`, `Запрос.Выполнить`, `Пустой`
- **Критичность:** Важно
- **Инструкция:** Агент должен порекомендовать использование `Выбрать()` вместо `Выгрузить()` для экономии памяти, если результат потом обходится в цикле.
