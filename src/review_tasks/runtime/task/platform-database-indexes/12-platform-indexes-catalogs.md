# Платформенные индексы справочников

Эти индексы создает платформа 1С автоматически в таблицах базы данных. Используй как справочник при ревью запросов, условий отбора, упорядочивания и настроек индексирования реквизитов справочников.

## Справочник

| Индекс | Условие |
|--------|---------|
| Ссылка | Всегда (кластерный) |
| Код + Ссылка | Длина кода > 0 |
| Наименование + Ссылка | Длина наименования > 0 |
| Реквизит + Ссылка | Реквизит индексируется |
| Реквизит + Код + Ссылка | Реквизит с доп. упорядочиванием, основное представление - код |
| Реквизит + Наименование + Ссылка | Реквизит с доп. упорядочиванием, основное представление - наименование |
| Реквизит | Справочник - критерий отбора по реквизиту |
| PredefinedID | Всегда |

## Подчиненный справочник

Дополнительные индексы подчиненного справочника:

| Индекс | Условие |
|--------|---------|
| Владелец + Ссылка | Длина кода = 0 |
| Владелец + Код + Ссылка | Длина кода > 0 |
| Владелец + Наименование + Ссылка | Длина наименования > 0 |
| Владелец + Реквизит + Ссылка | Реквизит индексируется |
| Владелец + Реквизит + Код + Ссылка | Реквизит с доп. упорядочиванием, представление - код |
| Владелец + Реквизит + Наименование + Ссылка | Реквизит с доп. упорядочиванием, представление - наименование |

## Иерархический справочник

При размещении групп сверху к индексу вместо `Родитель` добавляется `ЭтоГруппа`.

| Индекс | Условие |
|--------|---------|
| Родитель + [ЭтоГруппа] + Ссылка | Код = 0 и наименование = 0 |
| Родитель + [ЭтоГруппа] + Код + Ссылка | Длина кода > 0 |
| Родитель + [ЭтоГруппа] + Наименование + Ссылка | Длина наименования > 0 |
| Родитель + [ЭтоГруппа] + Реквизит + Ссылка | Реквизит индексируется |
| Родитель + [ЭтоГруппа] + Реквизит + Код + Ссылка | Реквизит с доп. упорядочиванием, представление - код |
| Родитель + [ЭтоГруппа] + Реквизит + Наименование + Ссылка | Реквизит с доп. упорядочиванием, представление - наименование |
