# Платформенные индексы регистров накопления

Эти индексы создает платформа 1С автоматически в таблицах базы данных. Используй как справочник при ревью запросов к регистрам накопления, условий по периоду, регистратору, измерениям, реквизитам, остаткам и оборотам.

## Основная таблица

| Индекс | Условие |
|--------|---------|
| Период + Регистратор + НомерСтроки | Всегда (кластерный) |
| Регистратор + НомерСтроки | Всегда |
| Измерение + Период + Регистратор + НомерСтроки | Измерение индексируется |
| Реквизит + Период + Регистратор + НомерСтроки | Реквизит индексируется |

## Таблица остатков

| Индекс | Условие |
|--------|---------|
| Период + Измерение1 + ... + ИзмерениеN | Для регистров "Остатки" (кластерный) |
| Период + Измерение | Измерение индексируется (начиная со второго) |

## Таблица оборотов

| Индекс | Условие |
|--------|---------|
| Период + Измерения | Для регистров "Обороты" (кластерный) |
| Измерение + Период | Измерение индексируется (начиная со второго) |
| Период + DimHash | Когда много измерений |
