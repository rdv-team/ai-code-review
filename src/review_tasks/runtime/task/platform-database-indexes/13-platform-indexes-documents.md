# Платформенные индексы документов

Эти индексы создает платформа 1С автоматически в таблицах базы данных. Используй как справочник при ревью запросов, условий отбора, упорядочивания и настроек индексирования реквизитов документов.

| Индекс | Условие |
|--------|---------|
| Ссылка | Всегда (кластерный) |
| Дата + Ссылка | Всегда |
| Номер + Ссылка | Длина номера > 0 |
| Реквизит + Ссылка | Реквизит индексируется |
| Реквизит + Дата + Ссылка | Реквизит с доп. упорядочиванием |
| Реквизит | Документ - критерий отбора по реквизиту |
| ПрефиксНомера + Номер + Ссылка | Длина номера > 0 |
