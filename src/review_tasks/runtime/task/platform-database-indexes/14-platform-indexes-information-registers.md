# Платформенные индексы регистров сведений

Эти индексы создает платформа 1С автоматически в таблицах базы данных. Используй как справочник при ревью запросов к регистрам сведений, условий по измерениям, периодам, регистратору, реквизитам и ресурсам.

## Непериодический регистр сведений

| Индекс | Условие |
|--------|---------|
| Измерение1 + Измерение2 + ... | Есть измерения (кластерный) |
| ИзмерениеN + (все остальные измерения) | ИзмерениеN - ведущее или индексируемое (не первое/единственное) |
| Реквизит + (все измерения) | Реквизит индексируется |
| Ресурс + (все измерения) | Ресурс индексируется |

## Периодический регистр сведений

| Индекс | Условие |
|--------|---------|
| Период + [Измерения] | Всегда |
| Измерения + Период | Есть измерения (кластерный) |
| ИзмерениеN + Период + остальные измерения | ИзмерениеN - ведущее или индексируемое (не единственное) |
| Реквизит + Период + измерения | Реквизит индексируется |
| Ресурс + Период + измерения | Ресурс индексируется |

## Регистр сведений, подчиненный регистратору

| Индекс | Условие |
|--------|---------|
| Регистратор + НомерСтроки | Всегда (кластерный) |

## Регистр сведений с периодичностью по позиции регистратора

| Индекс | Условие |
|--------|---------|
| Период + Регистратор + НомерСтроки | Всегда |
| Регистратор + НомерСтроки | Всегда |
| Измерения + Период + Регистратор + НомерСтроки | Есть измерения (кластерный) |
| Измерение + Период + Регистратор + НомерСтроки | Измерение индексируется |
| Реквизит + Период + Регистратор + НомерСтроки | Реквизит индексируется |
| Ресурс + Период + Регистратор + НомерСтроки | Ресурс индексируется |

## Итоги среза первых

| Индекс | Условие |
|--------|---------|
| Измерение1 + Измерение2 + ... + Период | Есть хотя бы одно измерение (кластерный) |
| Реквизит + Измерение1 + ... | Реквизит индексируется |
| Ресурс + Измерение1 + ... | Ресурс индексируется |
| ИзмерениеN + (все остальные измерения) | ИзмерениеN - ведущее или индексируемое (не единственное) |
