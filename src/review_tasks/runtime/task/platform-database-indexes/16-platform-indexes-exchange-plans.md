# Платформенные индексы планов обмена

Эти индексы создает платформа 1С автоматически в таблицах базы данных. Используй как справочник при ревью запросов, условий отбора, упорядочивания и настроек индексирования реквизитов планов обмена.

Индексы планов обмена аналогичны основным индексам справочника, но длина кода и наименования не может быть равна нулю: они всегда больше `0`.

| Индекс | Условие |
|--------|---------|
| Ссылка | Всегда (кластерный) |
| Код + Ссылка | Длина кода > 0 |
| Наименование + Ссылка | Длина наименования > 0 |
| Реквизит + Ссылка | Реквизит индексируется |
| Реквизит + Код + Ссылка | Реквизит с доп. упорядочиванием, основное представление - код |
| Реквизит + Наименование + Ссылка | Реквизит с доп. упорядочиванием, основное представление - наименование |
| Реквизит | План обмена - критерий отбора по реквизиту |
| PredefinedID | Всегда |
