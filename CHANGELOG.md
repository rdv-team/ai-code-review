# История изменений

Все значимые изменения проекта документируются в этом файле.

## [1.0.0] - 2026-09-25

### Добавлено

- Первый публичный релиз `review-tasks` для поэтапного ревью изменений 1С.
- Подготовка отдельного каталога ревью по ключу задачи GitLab или Merge Request. В проверку попадают изменённые модули BSL и тексты запросов в макетах отчётов СКД.
- Запуск Stage 1 и Stage 2 в Codex, Cursor и OpenCode с проверкой результата и созданием Markdown-отчёта.
- Skills `review-setup` и `review-init` для установки, настройки проекта и подготовки каталога задачи.
- Ручной запуск без Jira и внешних MCP-серверов; при необходимости можно подключить MCP для внешнего подтверждения замечаний.
- Запуск ревью со страницы Jira через расширение Chrome и локальный сервис, включая настройки проекта и отдельную инструкцию для задачи.
- Инструкции по установке, настройке Git и MCP, запуску ревью и диагностике ошибок.
